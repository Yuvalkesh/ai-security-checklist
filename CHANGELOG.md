# Changelog

## 1.0.0 — 2026-09-28

Initial English edition: 60 security controls across nine domains, a 12-question starting guide, four deployment profiles, 12 acceptance-test scenarios, private assessment and exception templates, an incident-response playbook and a supplier questionnaire.

This edition defines release gates and evidence requirements. It does not contain automated scans or claims about the security of any specific deployment.
