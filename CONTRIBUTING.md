# Contributing

Suggest improvements that make a control easier to implement, test or maintain.

A useful contribution explains the gap, proposes original wording, identifies affected control IDs and supplies a safe verification method. Keep controls vendor-neutral and avoid marketing claims or unsupported incident statistics.

For a control change, update `controls.json`, the corresponding section of `CHECKLIST.md`, any affected tests and `CHANGELOG.md`. Preserve stable IDs; do not silently reuse an old ID for a different control. New IDs also need rows in the assessment template.

Public issues are for generic documentation feedback only. Do not upload completed assessments, credentials, customer details, internal infrastructure information or unremediated system vulnerabilities. Use your organization's private reporting channel for those matters.

Contributions are provided under the repository's reuse terms.
